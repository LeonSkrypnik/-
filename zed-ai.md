## Free Tier Features
- **Full editor capabilities** - use Zed editor without any signup required
- **Bring Your Own API keys** - connect your own API keys from any provider
- **External agents** - use Claude Code, Codex, Gemini CLI, or other agents via ACP
- **No AI hosting** - the editor is free, AI features require paid subscription or BYO API key

## Trial Duration
- **14 days** free trial
- Includes **$20 of token credits**
- Automatically converts to Free plan when trial ends
- No cancellation needed to prevent conversion to paid

## Pricing (Pro Plan)
- **$10/month** for Zed Pro subscription
- Includes **$5/month** in token credits
- Additional usage billed at provider price +10%
- Unlimited edit predictions
- Access to Opus models

## Student Plan
- Free for verified university students for **1 year**
- Includes **$10/month** in token credits
