# Ellipsis Research Results

## Free Credits on Signup
- No specific credits system - uses a free tier model instead
- Free for public GitHub repositories (unlimited)
- 7-day free trial for private repositories (no credit card required)

## Models Offered
- **Proprietary models** from Ellipsis Labs
- They manage their own prompts, agents, and models to ensure state-of-the-art performance
- Does not support bringing your own LLM API keys

## Free Tier Features
- Free unlimited AI code reviews on public GitHub repositories
- AI code review on every commit
- PR summaries
- 7-day free trial for private repos (full features)
- No credit card required for trial

## Trial Duration
- **7 days** free trial for private repositories
- No credit card required to start
- All developers in the GitHub organization get access during trial

## Pricing Plans
| Plan | Price | Details |
|------|-------|---------|
| **Public Repos** | Free | Unlimited reviews, AI code review on every commit |
| **Pro** | $20/developer/month | Unlimited PR reviews, private repos, code generation, Q&A |
| **Enterprise** | $50+/developer/month | Custom integrations, advanced security, dedicated support |

## Key Notes
- GitHub-only integration (no GitLab, Bitbucket, or Azure DevOps)
- SOC 2 Type 1 certified with zero source code retention
- Can generate working, tested code via GitHub comments
- Learns from team feedback and custom style guides
- Reviews typically complete in 2-5 minutes per commit
- Founded by Y Combinator (W24 batch), based in New York
