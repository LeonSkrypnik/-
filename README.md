# Cline Research

## Free Credits on Signup
- Cline itself is free and open-source - no payment required to download and use
- No specific free credits bundle on signup
- Free models available through Cline Provider (tagged "FREE" in model selector, e.g., Gemini 2.0 Flash)
- Users can also use the "Bring Your Own Key" (BYOK) option with their own API keys at no cost
- For BYOK: free to use if connecting to local models via Ollama or LM Studio

## Models Offered
- **Through Cline Provider**: Claude Sonnet 4.6 (recommended), GPT-5.3 Codex, Gemini Pro 3.1, and more
- **BYOK Options**:
  - Anthropic (Claude models)
  - OpenAI (GPT models)
  - Google Gemini
  - DeepSeek
  - OpenRouter (multiple models)
  - AWS Bedrock
  - Local models via Ollama/LM Studio (completely free offline use)
- **Priority Recommendations**:
  - Reliability: Claude Sonnet 4
  - Value: Qwen3 Coder
  - Speed: Cerebras
  - Privacy: Any Ollama/LM Studio model

## Free Tier Features
- **Open Source (Free) Plan**:
  - VS Code extension
  - CLI access
  - Secure client-side architecture (code never touches external servers)
  - Bring your own API keys (BYOK)
  - MCP Marketplace access (hundreds of extensions)
  - Multi-root workspaces
  - Community support
  - Unlimited access to free-tagged models
  - No credit card required

## Trial Duration
- No traditional trial - the core product is free
- Teams plan was free through Q1 2026, now $20/month per user
- No time-limited trial for the free tier

## Pricing Summary
| Plan | Price |
