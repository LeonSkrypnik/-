# GitHub Student Pack

**Kilo Code is NOT currently part of the GitHub Student Developer Pack.**

## What is Available for Students

### Kiro Students (Separate Program)
Kiro (the IDE product, formerly Kilo) offers a **Kiro Students** tier with free access to eligible university students:
- **1,000 credits per month** for one full year
- Currently available at 11 universities: Arizona State, Cal Poly, Cal State Fullerton, Carnegie Mellon, Georgia Tech, Hampton University, NYU, University of Chicago, University of Toronto, University of Waterloo, UT Austin
- Sign up at kiro.dev/students using university-affiliated email
- No credit card required

### Kilo Code - Free Usage Options
Kilo Code itself can be used completely free:
- **Free models** - Kilo provides free models through Kilo Gateway (labeled "free" in model picker)
- **BYOK (Bring Your Own Key)** - Use your own API keys from free-tier providers
- **Open source** - The extension is free to install

### What GitHub Student Pack Includes
GitHub Student Pack includes **GitHub Copilot Pro** free for students (not Kilo Code).

## Summary
| Product | GitHub Student Pack | Student Program |
|---------|---------------------|-----------------|
| Kilo Code | Not included | Use free models or BYOK |
| Kiro (IDE) | Not included | Kiro Students (limited universities) |
| GitHub Copilot | Included (free) | N/A |

**Note**: Kiro and Kilo Code are related but separate products. Kiro is the IDE; Kilo Code is the open-source coding agent. Neither is in the GitHub Student Pack.
