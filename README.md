# Codeium

**Note:** Codeium rebranded to **Windsurf** in 2025. The core technology and brand now operate under the Windsurf name, though Codeium still exists as the underlying platform.

## Free Credits on Signup

- **25 prompt credits/month** on the free tier
- No credit card required - just email or GitHub login
- Credits reset every 30 days

## Models Offered

### Free Tier
- **Codeium Base model** - proprietary model trained on billions of lines of permissively licensed public code
- Unlimited code completions
- Standard context awareness (local files)

### Pro Tier ($15/month)
- **Codeium Cortex** - GPT-4 class reasoning model
- Access to GPT-4o and Claude Sonnet
- Expanded context length (full repository)
- 500 credits/month

### Teams/Enterprise
- Fine-tuned custom models
- Enterprise-specific models

## Trial Duration

- **No traditional free trial** - the free tier is available indefinitely
- Free tier has no time limit
- No credit card required

## Additional Notes

- Free tier uses proprietary Codeium models (not GPT-4 or Claude)
- Premium models (GPT-4o, Claude Opus) require Pro tier
- Enterprise offers self-hosted/air-gapped deployment options
- Student discounts available (.edu email) ~$6.90/month
