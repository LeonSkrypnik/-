# Cursor AI Research

## Free Credits on Signup
- **Free Hobby Plan**: Available immediately upon signup with no credit card required
- **Pro Trial**: 7-14 day free trial of Pro features for new accounts

## Models Offered
- **Premium Models**: Claude Sonnet, GPT-4o, Gemini (via manual selection)
- **Default/Auto Mode**: Uses built-in fast models for completions (no credits)
- **Opus Access**: Available on higher tiers (Pro+, Ultra)

## Free Tier Features (Hobby Plan)
| Feature | Limit |
|---------|-------|
| Tab Completions | 2,000/month |
| Premium (fast) Requests | 50/month |
| Slow Premium Requests | Limited |
| Agent Mode | Limited |
| Codebase Indexing | Basic |

- Full VS Code editor access
- Extensions, themes, keybindings work normally
- Basic AI chat available

## Trial Duration
- **Pro Trial**: 7-14 days (varies by source)
- Requires payment method for trial
- Can cancel before being charged

## Pricing Tiers
- **Hobby (Free)**: 2,000 completions + 50 premium requests/month
- **Pro ($20/month)**: Unlimited completions + $20 credit pool + 500 fast requests/month
- **Pro+ ($60/month)**: Same as Pro but $60 credit pool (3x)
- **Ultra ($200/month)**: $200 credit pool for power users
- **Business ($40/user/month)**: Team management features

## Notes
- The free tier is designed for evaluation; active developers typically exhaust limits within 1-2 weeks
- Auto mode completions don't consume credits - only manual premium model selections do
- Students may qualify for free/discounted Pro access via education program
- BYOK (Bring Your Own Key) supported - can use personal API keys to bypass limits
